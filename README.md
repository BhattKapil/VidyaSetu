# 🌉 VidyaSetu — Gamified Learning Platform

> **VidyaSetu** (विद्यासेतु) means *"Bridge of Knowledge"* in Sanskrit.  
> Built for the Odisha Government problem statement: education delivery in low-connectivity areas.

---

## 🚀 Features

### ✅ Implemented
- **Authentication** — Admin, Teacher, Student roles
- **Student Dashboard** — XP, levels, badges, streak tracking
- **Teacher Dashboard** — Quiz management
- **Quiz System** — MCQ with timer, XP rewards, instant feedback
- **Gamification** — XP points, level-up, achievement badges
- **Leaderboard** — Class rankings
- **AI Assistant UI** — Chat interface for study help
- **PWA / Offline Support** — Works without internet, Background Sync, Install prompt

### 🔜 Coming Soon
- Teacher Upload Notes (PDF)
- Teacher Upload Videos
- AI Assistant Backend
- Reminder System
- Smart Recommendations
- Live Quiz System
- Teacher Analytics

## 🛠 Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React 18 + TypeScript + Vite |
| UI | Tailwind CSS + shadcn/ui |
| State | TanStack Query + React Context |
| Offline | Service Worker + IndexedDB |
| PWA | Web App Manifest + Background Sync |
| Backend (planned) | Node.js + Express |
| Database (planned) | MongoDB |

---

## 📱 PWA Setup

The app is a fully installable PWA:
- Works offline with cached quizzes and dashboard
- Auto-syncs quiz results when back online
- Installable on Android/iOS home screen
- Push notifications for study reminders

## 🎯 Problem Statement

Designed for Odisha Government's initiative to provide quality education to students in low-internet areas. Key constraints:
- Must work on 2G/3G networks
- Must function fully offline
- Must run on low-end Android devices (2GB RAM)
- Lightweight bundle size
